# 评论型稿件专节

判为评论型时走这套；可覆盖通用开头与互动规则。

## 可信度从哪来（不靠身份，靠四样）

1. **事实密度**：时间、地点、数字、原话、截图；一句可核查事实抵三段抒情
2. **论证可见**：把推理链摆出来，不只给结论
3. **视角独家**：别人骂 A，你指出结构性问题在 B——护城河
4. **主动交出反方**：先给 strongest objection 并回应——可信度 + 评论区引信

## 开头顺序

**结论/反常识判断 → 最短事实支撑 → 展开论证**  
禁止：长铺垫复述事件 → 引述各方 → 最后才给看法（读者第二段就走）。

## 互动三条防线

- 提问框在**观点层面**，不引身份对立
- 预设 strongest objection 并当场回应
- 未定论事件用「目前公开信息显示」「从已披露的看」——合规缓冲

## 额外红线

- ❌ 对未定论公共事件下确定性断言
- ❌ 定性词直接扣人（名誉风险）
- ❌ 追热点但超出账号专业范围（稀释垂直度）
- ⚠️ 社会、时政、医疗、金融：确认账号主体资质；无资质权重天然吃亏
