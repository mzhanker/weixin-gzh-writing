# 四型规则与身份前置

## 四型天然强弱

| 类型 | 天然强项 | 天然短板 | 首要改写重心 |
|---|---|---|---|
| **经验型**（我做过/我见过） | 完读、分享 | 收藏、互动 | 造收藏钩子；经验→可执行清单 |
| **评论型**（对事件/现象的判断） | 互动、分享 | 收藏、关注转化 | 论证链摆出来；合规与事实核查 |
| **清单/教程型**（步骤/模板/盘点） | 收藏、关注转化 | 分享、情绪 | 加金句与情绪锚点 |
| **故事型**（叙事驱动） | 完读 | 分享、关注转化 | 结尾提炼可转发的「道理」 |

**差异化合格线**：
- 评论型：分享、互动应显著高于通用线
- 清单型：收藏率应 ≥3%（高于通用 2%）
- 故事型：关注转化若 <1%，说明结尾没升华成关注理由

**混合型**：取占比最高两型规则叠加，并在改动说明里告知判定依据。

## 身份前置判断（改稿前必须先定）

**唯一标准：身份在这篇里是「论据」还是「标签」？**

| | 经验型 / 故事型 | 评论型 |
|---|---|---|
| 身份作用 | **论据**——「我做过」是证据 | **标签**——读者预判立场 |
| 处理 | 前置到前 100 字，越硬越好 | 后置或删除，除非是论据 |
| 可信度来源 | 亲身经历 | 论证严密 + 视角独家 + 事实密度 |
| 头号风险 | 埋太深，读者不信 | 一上来亮身份，先贴标签站队 |

**评论型例外（必须前置身份）**：
1. 有亲历/现场/内部信息 → 身份=独家论据
2. 专业领域判断（医疗、法律、金融、教育）→ 身份=通行证

**判断句**：删掉身份后说服力会不会塌？会塌 → 前置；不塌 → 后置或删。

## 按类型分化的常用动作

### 开头钩子
- 经验型：最硬背景（年限、代表作、独特经历）进前 100 字 + 内容承诺
- 评论型：不亮身份；三选一——反常识判断 / 具体场景细节 / 共识缺口；再补内容承诺
- 清单型：开头明示「这份清单解决什么问题」
- 故事型：场景/冲突切入 + 内容承诺

### 结尾提问
- 经验/清单 → 问自身处境（ABC 选项）
- 评论 → 问观点判断（二选一），框在观点层，不引身份对立
- 故事 → 问相似经历

### 关注引导
- 经验/故事 → 人设化（持续能得到什么）
- 评论 → 价值承诺化，不靠人设
- 清单 → 资源化（模板/清单更新）

### 收藏钩子
- 经验/评论：某节改成可执行清单 +「建议收藏，下次……前翻出来」
- 清单型：不必硬加，开头明示用途即可

### 金句类型（别串味）
- 经验：感悟句｜评论：判断句｜清单：结论句｜故事：升华句

### 高潮位置（结构体检用）
- 经验：最可复制的方法｜评论：最锋利的判断｜清单：最意外的一条｜故事：情绪/转折
- 末节若不是全篇最强 → 删或并入
